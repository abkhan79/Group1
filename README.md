# FastFood House Website (Group1)

## Project Description
FastFood House is a responsive multi-page restaurant website built with HTML, CSS, and JavaScript. The site includes a homepage, menu/services page, specials page, about page, and contact page to showcase a fast-food brand with modern layout, navigation, and interactive elements.

## Team Members and Roles
- **Bibek Yadav**: Built `special.html`, `services.html`, and `style.css`.
- **Aliya Khan**: Built `index.html`, `contact.html`, and `README.md`.
- **Brandon Bahena**: Built JavaScript functionality and `about.html`.
